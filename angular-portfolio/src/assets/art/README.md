# Art & Culture Photos

Drop your photos from the **Printemps des Arts** (ESTIN) and other campus events here,
using exactly these filenames so they appear automatically in the gallery:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`

Any format supported by browsers works (`.jpg`, `.png`, `.webp`) — if you use another
extension, update the `src` values in
`src/app/components/arts/arts.ts`.

Photos without a matching file render as an elegant "Photo coming soon" placeholder.
